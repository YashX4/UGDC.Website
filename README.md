# UMass Game Dev site (integrated prototype)

Home, loader, menu, poster wall and cartridge table in one page, in the final Klein palette.

Run: `npx serve -l 8080 .` (or `python3 -m http.server 8080`) and open http://localhost:8080. It will not work from `file://`.

Read HANDOFF.md for everything else and CLAUDE.md for the rules.
